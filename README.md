# The Bible Songs

**The Bible Songs** 是由 **New Creation Worship（更新敬拜团）** 制作的敬拜音乐品牌。

我们创作与重新演绎中文敬拜音乐，包括经典赞美诗、原创敬拜歌曲、经文歌曲、诗篇歌曲，以及其他能够带领人归向神的音乐。

> Songs that lead hearts to God.

## Brand

- 主品牌：The Bible Songs
- 制作团队：New Creation Worship（更新敬拜团）
- 固定署名：Produced by New Creation Worship
- 核心气质：敬拜、真理、盼望、美好、爱
- 视觉方向：深海军蓝、金色、晨光、海面、宁静而庄重的敬拜氛围
- 品牌原则：AI 是制作工具，不作为对外品牌身份

## Content Scope

本项目不限定为“经典赞美诗翻新”。未来内容包括但不限于：

- 经典中文赞美诗的新编曲与重新演绎
- 原创敬拜歌曲
- 圣经经文与诗篇歌曲
- 安静敬拜与纯音乐
- 节期、儿童及其他主题敬拜作品
